# 🚀 S.L.S.I. Desktop Assistant

S.L.S.I. is a cross-platform Electron-based AI desktop assistant built to handle advanced natural language OS commands, administrative elevation, Wi-Fi diagnostics, and custom web profile navigation.

---

## ⚙️ Prerequisites

Make sure you have Node.js installed on your system — [Download Here](https://nodejs.org/).
